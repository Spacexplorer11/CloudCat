CloudCat

CloudCat is a free, browser-based endless runner inspired by the Chrome Dino game — jump a cat over obstacles as the pace picks up, no download or install required.

How to play

Press space (or tap on mobile, landscape orientation) to jump. Avoid the obstacles and see how far you can get before you're caught out.

Built with Rust

CloudCat is written entirely in Rust using the Macroquad game framework, compiled to WebAssembly so it runs directly in your browser. The full source is open on GitHub.
